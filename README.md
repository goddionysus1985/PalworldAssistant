## 📦 Разделы приложения

| Раздел | Описание |
|--------|----------|
| 🏠 **Начало** | Советы для новичков — что игра не объясняет сама |
| 🔧 **Механики** | Скрытые механики: IVs, конденсор, SAN, патфайндинг |
| 🏡 **База** | Топ S-тир специалисты для каждой работы с фото |
| ⚔️ **Боёвка** | Лучшие боевые палы, комбо и тактика |
| ✨ **Пассивки** | Все лучшие пассивки с реальными цифрами |
| 🧬 **Разведение** | Пошаговый гайд по разведению + ключевые рецепты |
| 💡 **Лайфхаки** | Скрытые трюки и оптимизации |
| 🗺️ **Эндгейм** | Башни, рейды, легендарные палы |
| 🔥 **Стихии** | Таблица эффективности стихий |
| 🧮 **Калькулятор** | Калькулятор разведения (прямой + обратный поиск) |
| 📍 **Карта** | Интерактивная карта: легендарки, данжи, торговцы, руда |
| 🍽️ **Еда** | Калькулятор еды: подбор по цели (работа/SAN/бой) |
| 🏗️ **Планировщик** | Визуальная сетка для расстановки зданий базы |
| 📊 **Технологии** | Интерактивное дерево технологий с приоритетами |
| 🎯 **Боссы** | Детальные гайды по всем 5 боссам башен |
| 💰 **Золото** | Лучшие методы фарма золота |

## ⚡ Особенности

- **Полностью на русском языке** — включая названия палов
- **Фото палов** с cdn.paldb.cc (реальные игровые иконки)
- **Работает без сервера** — чистый HTML/CSS/JS
- **Фильтр по уровню** — Новичок / Средний / Опытный
- **Глобальный поиск** по всему контенту
- **Кнопка "назад наверх"** и адаптивный дизайн
- **Сохранение прогресса** дерева технологий в localStorage

## 🛠️ Технологии

- Vanilla HTML5 / CSS3 / JavaScript (без фреймворков)
- Canvas API — интерактивная карта и планировщик базы
- localStorage — сохранение изученных технологий

## 📊 Данные

Все игровые данные актуальны для **Palworld 1.0** и основаны на:
- Официальных игровых файлах (через сообщество)
- [paldb.cc](https://paldb.cc) — база данных палов
- Reddit-сообщество и проверенные гайды
